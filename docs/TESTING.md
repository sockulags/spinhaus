# Testchecklista – Spinhaus

Gå igenom punkterna när du har tid. Skriv ner vad som inte fungerar (punktnummer räcker) och
exportera loggen: **Enheter → Logg → Exportera**.

## 0. Installera
1. Öppna https://github.com/sockulags/spinhaus/releases på plattan.
2. Ladda ner senaste `spinhaus-0.1.X.apk` och öppna filen.
3. Första gången: tillåt "Installera okända appar" för webbläsaren.
4. Senare versioner: appen visar "Ny version finns" på hemskärmen → Uppdatera → Installera. Historiken finns kvar.
5. Stäng Zwift och Zwift Companion helt innan du testar.

## 1. Start och profiler
- [ ] Appen ber om Bluetooth- och notisbehörighet → tillåt.
- [ ] Skapa din profil (namn, FTP, vikt, maxpuls, språk).
- [ ] Skapa hennes profil. Byt mellan profilerna (tryck på namnet uppe till höger på hemskärmen).
- [ ] Byt språk i en profil → texterna byter språk.

## 2. Para cykeln (Enheter)
- [ ] Trampa några varv. Trainern (KICKR CORE …) dyker upp → "Använd som trainer".
- [ ] Watt, kadens och fart visas och ändras när du trampar.
- [ ] Tryck "ERG 150 W" → motståndet ändras. "Lutning 5 %" → tyngre. "Platt" → lättare.
- [ ] Tryck på en knapp på styret. "Zwift Ride" dyker upp → "Lägg till".
- [ ] Status blir "Ansluten" och "Senaste knapp" visar knappnamnet när du trycker.
  - Står det **"Låst av Zwift"**: följ instruktionen i kortet (öppna Zwift, para, stäng Zwift).
    Skriv ner om det fungerade.
- [ ] Pulsband/Garmin: dyker upp under Puls → "Använd för mig". Pulsen visas.
- [ ] Hon: välj hennes profil och para hennes Garmin på samma sätt.
- [ ] Tryck "Tillåt bakgrundsanvändning".
- [ ] Starta om appen → allt ansluter automatiskt (grön prick på hemskärmen).

## 3. Fri cykling
- [ ] Hem → Snabbstart. Trampa: tiden startar, watt/fart/distans uppdateras.
- [ ] Växla med höger/vänster växelknappar → växeln på skärmen ändras och motståndet känns.
- [ ] ▲▼ på vänster knappsats ändrar lutningen (manuell lutning).
- [ ] ◀ ▶ byter dashboard-sida, Z visar/döljer grafen, Y pausar.
- [ ] Sluta trampa → "Pausad" efter några sekunder. Trampa igen → fortsätter.
- [ ] Avsluta → Spara → sammanfattningen visas. Finns i Historik.
- [ ] Fri cykling → välj "Den långa klättringen" → backen blir tyngre efter några km.

## 4. ERG-pass
- [ ] Pass → välj ett kort pass (t.ex. "Snabba 20"). Watt-målen stämmer mot din FTP.
- [ ] Start: trainern håller målwatt. Vid intervallbyte: nedräkning 3-2-1 och röst.
- [ ] Höger växelknapp +/− ändrar intensiteten ±5 %.
- [ ] Håll in A ~1 s → hoppar över intervallet.
- [ ] B → ERG av (växla själv) / på igen.
- [ ] Trampa riktigt sakta (< 40 rpm) några sekunder → "Låg kadens – motståndet sänkt", och det
      lättar. Öka kadensen → målet kommer tillbaka mjukt.
- [ ] "Spurtset" eller ett pass med Max/Fri: ERG släpper och du växlar själv.

## 5. FTP-test
- [ ] Hem → FTP-test → Ramptest. Kör tills du inte orkar (kadens < 50 i 5 s avslutar testet).
- [ ] Efter testet: "Ny FTP: X W" → Spara. FTP i profilen uppdateras.
- [ ] Utveckling: FTP-kurvan visar det nya värdet.

## 6. Historik och utveckling
- [ ] Historik: veckosummering och lista. Filtret Mig/Alla fungerar.
- [ ] Öppna en åktur: grafer, zoner, bästa värden. Sätt känsla och anteckning → Spara.
- [ ] Utveckling: veckovolym, effektkurva, form (CTL/ATL/TSB).

## 7. Anpassning
- [ ] Inställningar → Layout: välj "Datanörd", lägg till/flytta en ruta. Syns på åkskärmen.
- [ ] Inställningar → Knappar: ändra en knapp. Fungerar under åkturen.
- [ ] Ljud: Av / Pip / Pip + röst.
- [ ] Växelkänsla: ändra och prova i fri cykling.

## 8. Egna pass och import
- [ ] Pass → Nytt: bygg ett pass med block, spara, kör.
- [ ] Pass → Importera: välj en .zwo-fil (t.ex. från whatsonzwift.com) → passet dyker upp.
- [ ] Ett pass → Dela .zwo.

## 9. Säkerhet
- [ ] Inställningar → Skapa backup → spara t.ex. på Google Drive.
- [ ] Mitt i en åktur: stäng appen via "senaste appar". Öppna igen → åkturen finns i historiken
      ("återställd").

## 10. Träningsplaner (v2)
- [ ] Hem → "Träningsplaner" → välj en plan → Starta idag.
- [ ] Hemkortet visar vecka, antal klara och nästa pass med graf.
- [ ] Starta nästa pass från kortet, kör en stund, avsluta och spara → passet är markerat Klar.
- [ ] Hoppa över ett pass → nästa pass visas. Ångra i Min plan.
- [ ] Byt ett pass mot ett annat från biblioteket.
- [ ] Min plan: alla veckor med status. Ett missat pass går att köra med "Gör nu".
- [ ] Hennes profil kan ha en annan plan samtidigt.

## 11. Film under passet (v2)
- [ ] Starta ett pass → 🎬 Film → Tillåt "visa över andra appar" (första gången).
- [ ] Öppna YouTube/Netflix → en ruta med watt, mål, puls och nedräkning ligger ovanpå.
- [ ] Dra rutan, dubbeltryck (fler värden), tryck (tillbaka till Spinhaus – rutan försvinner).
- [ ] Höger power-up pausar/startar filmen. Sluta trampa → filmen pausas; trampa → fortsätter.
- [ ] Rösten hörs vid intervallbyte och filmljudet sänks kort.
- [ ] Växla/ändra intensitet med styret medan filmen visas.
